Micro-Macro Criticality · About

About this simulator

This simulator illustrates the core setup of the paper: how dynamical regimes at the micro level (inside each agent) relate to collective behavior at the macro level (across interacting agents).

Agents are placed in a 2D toroidal space and communicate only through binary light signals. Each agent contains an internal probabilistic reservoir; its light state is read from a designated neuron. At each macro step, agents receive egocentric exteroceptive observations of illuminated neighbors within vision radius $v_r$, and these inputs perturb their internal reservoir dynamics.

The key question is whether near-critical micro dynamics are sufficient to produce macro-level critical-like avalanche statistics, or whether collective behavior is primarily constrained by interaction topology and activity propagation.

Reservoir · micro level

Each agent carries an independent Beggs–Plenz probabilistic reservoir of $N$ fully-connected neurons. At each micro step every active neuron independently tries to activate every other with probability $p$. For $n$ active sources the firing probability of any target is:

$$P(\text{fires}) = 1 - (1-p)^n$$

$$\sigma = p\cdot(N-1),\quad p_c = \frac{1}{N-1}$$

The branching ratio determines the regime: at $\sigma < 1$ activity dies exponentially (subcritical); at $\sigma > 1$ it grows without bound (supercritical); at $\sigma = 1$ avalanches follow a power law (critical). Macro level · collective dynamics

At the macro level, agents are coupled through perception: only neighbours within vision radius $v_r$ contribute input to each reservoir. This spatial filtering reshapes collective dynamics even though all agents share the same micro rule $p_{\mathrm{micro}}$.

As shown in the paper, changing $v_r$ moves the effective critical point in $p_{\mathrm{micro}}$. In practice, the system is critical along a band $p^*(v_r)$ (the bright diagonal in the heatmap), not at a single global $p$ value.

$$A(t)=\sum \text{lights}(t),\quad \hat{\sigma}_{eff},\quad \mathcal{L}$$

From this signal we extract avalanche size and duration, estimate $\hat{\sigma}_{\mathrm{eff}}$, and compute the criticality score $\mathcal{L}$ from power-law goodness-of-fit.

Interpretation by region: below the critical band activity quickly dies (subcritical), on the band avalanches are scale-free (critical), and above it activity tends to persist with many censored avalanches (supercritical).

Avalanche Extraction

The same Beggs–Plenz micro rule as above, but with a fixed $N=64$ reservoir reservoir and no automatic reseeding. Each button press seeds a single active neuron at time 0 on the left; the raster fills toward the right for up to 260 micro-timesteps (the observation window). Drag $\sigma$ to see how far a cascade typically spreads before it dies.

Two kinds of events are set aside when building serious avalanche statistics — and this demo is meant to mirror that logic. First, cascades that still have activity when the window ends are censored: their true size and duration are unknown, so they are excluded from distributions that require a complete avalanche (in index.html, an avalanche still open at the end of a rep is dropped the same way). Second, trivial cascades — those with no real extent beyond the minimal initiating pattern (in practice, integrated size 1: only the seed column, then immediate quiescence; sometimes described as zero “length” in the sense of no propagated activity) — are too degenerate to inform a power-law tail. They may still appear in raw tallies, but the paper’s MLE uses $x_{\min}=2$ on both size and duration, which excludes those smallest events from fitting only.

The raster uses micro dynamics, but the measurement recipe is the same one used at macro in the live simulator: at each time step, add the number of active units (here, neurons in one reservoir; there, agents with the light neuron ON), and sum that over the avalanche until activity hits zero within the window. Only the choice of elementary unit changes; the construction is scale-independent. Time 0 includes the seed, so the reported size is integrated activity through the cascade, not a separate “postsynaptic-only” count with the drive removed.

Parameters

$v_r$ (vision radius) — spatial coupling range. Larger $v_r$ means more neighbours per agent and stronger macro-level coupling.

$p_{\mathrm{micro}}$ — homogeneous connection weight in each reservoir. The reservoir critical point is $p_c = 1/(N-1)$ where $N$ is the number of neurons. Below p_c activity dies; above it, it self-sustains.

Avalanche size & duration

An avalanche is a maximal contiguous run of macro steps where at least one agent is lit ($A_l(t)=\sum_i l_i(t)>0$). Its size is the cumulative count of active agents summed over all steps in the run; its duration is the number of steps. Avalanches that are still active at the end of a rep window are discarded (censored), matching the paper’s methodology. Smallest (trivial) events are handled separately when estimating power-law exponents ($x_{\min}=2$); see Avalanche Extraction above.

Criticality & power laws

$$P(x)\propto x^{-\alpha},\quad x_{min}=2$$

The MLE exponent α is estimated via the discrete Clauset et al. (2009) formula.
